### SO 编辑器
- 定义：Fler 应用的核心功能模块，提供对 Android 共享对象文件（.so）的结构浏览、反汇编查看、十六进制编辑和字节修改功能。支持撤销操作、交叉引用查看、函数导航等逆向分析常用功能。
- 别名：so_editor、SO分析器

### PP 条目
- 定义：Pool Pointer 条目的缩写，是 Flutter 应用中用于内存池管理的指针结构。在逆向分析中，PP 条目包含重要的元数据和字符串信息，是理解 Flutter 应用行为的关键。
- 别名：pp_entry、Pool Pointer

### Blutter 分析
- 定义：使用 Blutter 引擎对 Flutter 应用的 libapp.so 进行静态分析的过程，主要提取 Dart 类定义、方法签名、PP 条目映射等 Flutter 特有的元数据信息。
- 别名：blutter_analysis、Dart分析

### 引擎注册中心
- 定义：EngineRegistry 类，负责管理和调度不同的二进制分析引擎（Rizin、SelfAnalysisEngine等），根据能力优先级自动选择合适的引擎执行分析任务。
- 别名：engine_registry、分析引擎管理器

### MCP 服务
- 定义：Model Context Protocol 服务，提供标准化的 HTTP API 接口，允许外部 AI 工具（如 Claude Desktop）远程调用 Fler 的分析能力，支持 SSE 和 Streamable HTTP 两种协议。
- 别名：mcp_server、AI接口服务

### 撤销系统
- 定义：BackupManager 实现的字节修改撤销机制，为每个 SO 文件维护独立的 undoStack，支持多次撤销操作，并将补丁记录持久化到 filesDir/undo/ 目录。
- 别名：undo_system、补丁管理

### 地址转换
- 定义：AddressTranslator 提供的虚拟地址与文件偏移之间的转换功能，用于在不同地址空间之间进行映射，特别是在 ASM 方法跳转到 SO 编辑器时进行地址换算。
- 别名：address_translation、地址映射

### 引擎包
- 定义：包含特定版本 Blutter 引擎的动态库文件（dartvm_x.y.z.so）及其依赖的压缩包，支持从远程源下载和版本管理，预置在 fler-engines/ 目录中。
- 别名：engine_package、dartvm包

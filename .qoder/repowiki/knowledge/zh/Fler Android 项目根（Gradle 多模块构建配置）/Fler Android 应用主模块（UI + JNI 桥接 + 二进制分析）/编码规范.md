- Hilt 依赖注入统一通过 `@Module` + `@InstallIn(SingletonComponent::class)` 声明单例组件，并由 `@Provides` 方法构造，避免在业务代码中手动 new。
- JNI 绑定以 Kotlin 对象封装（如 `CapstoneBindings`、`RizinBindings`），对应 C++ `jni_bridge/*.cpp` 中的 `extern "C"` 导出函数，形成清晰的 Java→C++ 单向边界。
- 分析引擎通过 `BinaryAnalysisEngine` 接口抽象，具体实现（RizinEngine、SelfAnalysisEngine）注册到 `EngineRegistry`，便于后续扩展新引擎。
- Room 数据层严格分离 `entity/*`（@Entity 类）、`dao/*`（@Dao 接口）与 `AppDatabase`，实体字段命名与列名保持一致。
- Compose 界面遵循 Screen + ViewModel 模式，ViewModel 通过 `@AndroidEntryPoint` 注入依赖，状态通过 `remember` / `mutableStateOf` 管理。
- CMake 构建中所有第三方库均以 `STATIC IMPORTED` 方式引入，并通过 `${FLER_LIBS_DIR}` 变量集中指向 `../../../libs/arm64-v8a`，保持 ABI 一致性。
